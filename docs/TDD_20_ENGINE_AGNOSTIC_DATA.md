# TDD 20: Engine-agnostic data (Stage 115)

The first stage of the engine-agnostification program (the plan: the game logic, rendering decisions,
physics, level IO and tooling native and engine-free behind a C API, Godot a thin host; stages 115-119).
This stage changes no behaviour: it builds the safety net every later port is checked against, and takes the
data pipelines off Godot.

Background: TDD_10 (the native core), TDD_15 (performance), docs/WORKFLOW.md (the gates and pipelines).
